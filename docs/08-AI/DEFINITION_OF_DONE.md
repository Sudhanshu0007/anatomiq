## Purpose

This document defines what it means for AI-assisted work to be complete in AnatomIQ. It sets the minimum bar for acceptance, review, and validation.

## Scope

### In scope

- Documentation completion criteria.
- Task completion and validation criteria.
- Review and traceability expectations.
- Milestone readiness expectations.

### Out of scope

- Team process details outside the documentation set.
- Release management bureaucracy not yet needed for the MVP.
- Tool-specific completion automation.

## Done criteria

A task or document is done only when all relevant items below are true:

- The output matches the governing document(s).
- The scope is complete and does not drift.
- Required links, IDs, and references are present.
- Validation has been performed and recorded.
- Accessibility, recovery, and medical constraints are preserved where relevant.
- No invented claims, sources, approvals, or tests are present.
- The output is ready for human review or merge.

## Milestone-level done criteria

- The milestone’s documents exist and are internally consistent.
- The milestone’s outputs match the next planned phase.
- Open questions are recorded rather than hidden.
- Required validation paths are defined.
