## Purpose

This document records the release notes structure for the V0.1 AnatomIQ release. It should summarize what the release includes, what it does not include, and what changed relative to the previous documented state.

## Release summary

V0.1 is the first scoped AnatomIQ release candidate focused on the cardiovascular lesson MVP. It is intended to represent the approved MVP learning journey and its supporting evidence, not a complete anatomy platform.

## Included scope

- Cardiovascular orientation and circulation lesson.
- Guided lesson controls, annotations, and review flow.
- Accessibility and recovery support for the core journey.
- Documented medical simplifications and limitations.

## Not included

- Additional body-system lessons.
- Pathology or diagnosis content.
- Accounts, monetization, or social features.
- Any feature not covered by the approved MVP scope.
