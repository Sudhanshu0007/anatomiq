## Purpose

This checklist records the minimum release gates for the AnatomIQ cardiovascular MVP. It is intended to be used against a real release candidate and must not be marked complete without evidence.

## Scope

### In scope

- Release readiness checks.
- Evidence pack completeness.
- Decision criteria for release readiness.

### Out of scope

- Product marketing approvals.
- Future-system release criteria.
- Infrastructure procurement details.

## Checklist

- [ ] The MVP documentation set is complete for the intended release scope.
- [ ] The cardiovascular lesson route matches the approved medical content.
- [ ] The core learner journeys pass validation evidence review.
- [ ] Accessibility checks are complete and unresolved issues are documented.
- [ ] Performance checks are complete and unresolved issues are documented.
- [ ] Medical review is complete and simplifications are recorded.
- [ ] Known limitations are documented in learner-appropriate language.
- [ ] Release notes are ready and honest about scope.
- [ ] The release owner has reviewed the evidence pack.

## Release decision guidance

- Do not mark the release ready if a Must requirement lacks evidence.
- Do not release if a scientific-integrity issue or accessibility blocker remains unresolved.
- Do not claim completeness when only a prototype or draft build exists.

## Acceptance criteria

- [ ] The checklist covers the evidence pack and release decision gates.
- [ ] The checklist is honest about evidence requirements.
- [ ] The checklist aligns with the release and validation plan.
