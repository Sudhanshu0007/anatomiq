## Purpose

This document defines the overall design vision for AnatomIQ. It establishes how the product should look, feel, and behave so that later brand, UI, motion, and 3D decisions stay aligned.

## Scope

### In scope

- High-level design intent.
- Visual tone and product atmosphere.
- Clarity, trust, and educational emphasis.
- How the design system should support the learner experience.

### Out of scope

- Final logo, palette, component, or asset details.
- Implementation-specific rendering or interaction logic.
- Marketing design or launch-campaign visuals.

## Design vision

AnatomIQ should feel like a precise, cinematic learning environment that helps learners understand the human body through clear visual structure and controlled motion.

The design must support comprehension first, with aesthetics serving the teaching objective rather than competing with it.

## Design goals

- Make the active anatomy obvious.
- Keep the learner oriented at every step.
- Present the body as a coherent system rather than disconnected labels.
- Support reusable lessons without redesigning the experience every time.

## Design principles

| Principle | Meaning in practice |
| --- | --- |
| Clarity first | Every visual element must help the learner understand something important. |
| Control always | The learner must be able to pause, inspect, and return safely. |
| Science over spectacle | Visual interest is useful only when it improves comprehension. |
| Reuse over one-off styling | Shared patterns should work across future systems. |
| Calm precision | The product should feel focused, polished, and trustworthy. |

## Design language

- Use strong hierarchy to separate lesson focus, supporting details, and controls.
- Use motion and colour intentionally, not as decoration.
- Keep the interface visually quiet around the anatomical scene.
- Allow the 3D content to remain the main teaching surface.
