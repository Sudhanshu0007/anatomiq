## Purpose

This document defines the typography direction for AnatomIQ. Typography must make scientific content readable, hierarchical, and calm to scan.

## Scope

### In scope

- Type role hierarchy.
- Readability and density guidance.
- Usage rules for lesson text, labels, and controls.
- Accessibility and legibility considerations.

### Out of scope

- Final font licensing selection.
- Implementation-specific font loading.
- Brand iconography details.

## Typography principles

- Typography must support clarity before expression.
- Scientific terms should remain readable at a glance.
- Hierarchy should help the learner know what to read first.
- Text must remain legible over dark or busy backgrounds.

## Type roles

| Role | Intended use |
| --- | --- |
| Display | Entry title, major section titles, and lesson-level headings |
| Heading | Panel titles, stage labels, and important structural grouping |
| Body | Lesson explanations, annotations, and supporting text |
| Label | Anatomy names, controls, and concise metadata |
| Utility | Help text, scope notes, and secondary metadata |

## Type usage rules

- Use clear hierarchy to separate title, explanation, and controls.
- Avoid overly decorative letterforms that reduce readability.
- Keep line length and spacing comfortable for educational reading.
- Labels for structures should remain readable even when the scene is visually dense.
- The same typographic scale should be reused across the product where practical.

## Accessibility rules

- Text must be readable at the supported reference size without unnecessary zoom.
- Contrast must support all text roles.
- Important labels and controls must not depend on tiny text.
- Long educational explanations must remain scannable.

## Typography acceptance criteria

- [ ] The hierarchy supports fast scanning and reading.
- [ ] Lesson text remains readable in dense scenes and overlays.
- [ ] The type system reinforces calm, scientific clarity.
- [ ] AI Context is current.

## Open questions

- [ ] Should the product use a humanist sans serif, a geometric sans serif, or a more editorial type family?
- [ ] How much differentiation is needed between lesson text and UI labels?
